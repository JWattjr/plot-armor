# Two-minute demo

0:00 — Open Discover without a wallet. Identify StudioNet and simulated GEN. Select a real upcoming episode and show its frozen question, entry cutoff and settlement date.

0:20 — Open a historical rehearsal. Explain that its known result earns no competitive points. Inspect definitions and deadlines, then choose “I’ve watched — reveal result” to inspect the exact frozen proposition and evidence. Historical proposition wording can itself be a spoiler, so it is shielded too. Open the permanent Wikipedia revision and the settlement receipt. Repeat briefly for YES, NO and multiple choice using the recorded market list.

0:50 — Open Proof and inspect the rejected subjective question. Explain why ambiguity cannot be turned into an arbitrary winner. Describe the retryable UNCLEAR state and the deterministic void/refund deadline; use the real void only if one actually finalized, otherwise clearly show the tests that cover it.

1:10 — Open Proof’s eleven-wei demonstration. It explicitly identifies the preserved previous pool; the current pool uses identical source. Show its stake, code-calculated payout, settlement receipt, claim parent and credited native child. Verify the paid account read-back. Do not imply that a finalized parent alone proves native credit.

1:30 — Show Propose a market and My predictions. Free calls require a wallet but no stake. The Activity page tracks reload-safe transaction hashes and distinguishes accepted from finalized success or error.

1:45 — Open the public repository and deploy/proof.json. Show the four contracts and two judgment points. Mention npm run settle for future eligibility and npm run verify:proof for independent read-only verification. The owner submits the Portal draft.
